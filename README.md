# hDC Host

Landing page de uma empresa fictícia de hospedagem.

Projeto desenvolvido para praticar HTML5 e CSS3, com foco em estruturação de páginas, Flexbox e responsividade.

## Tecnologias

- HTML5
- CSS3
- Flexbox
- Media Queries
- Font Awesome

## Funcionalidades

- Layout responsivo
- Seção de serviços
- Planos de hospedagem
- Busca de domínio
- Formulário de contato
- Menu de navegação
